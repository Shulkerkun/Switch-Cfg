Switch Configurator

Starter didattico in HTML/CSS/JavaScript con sezione IP scan e configurazione base switch.

IP Scan

Pronto. Questo starter usa una modalità demo. Per una scansione reale serve un piccolo backend locale.
IP Stato HTTP Dettagli
In un normale browser, una pagina HTML/JS non può fare una vera scansione LAN via ICMP/TCP arbitrario per limiti di sicurezza. La strada corretta è: frontend web + servizio locale HTTP (Node/Python/C#) che esegue la scansione e restituisce JSON.
